HanziPractice — обновление проекта

Основа: полный архив HanziPractice.zip от 04.11.2026.
Поверх основы применены ранее подготовленные обновления интерфейса, а также новые изменения из текущего обсуждения.

Что входит:
- при ошибочной проверке эталон отображается под пользовательскими чертами, с цветными номерами эталонных черт; поле подсвечивается красным и ждёт кнопку «Повторить»;
- пользовательские черты нумеруются чёрными цифрами рядом с началом каждого штриха, в фактическом порядке рисования;
- при правильной проверке поле подсвечивается зелёным, эталон показывается 0,7 секунды;
- уровни точности L (<20%), M (<15%), H (<10%), по умолчанию L, с сохранением выбора;
- изменение размера поля щипком от 60% до 90% ширины экрана и сохранение размера;
- постоянный счётчик попыток отдельно по каждому иероглифу;
- повторное нажатие на выбранную тему предлагает другой иероглиф;
- экран прогресса: нажатие на тему открывает список иероглифов; выбор иероглифа возвращает на главный экран к нему;
- светлее серый №8, коричневый №9;
- озвучивание иероглифа кнопкой динамика;
- системное имя HanziPractice и предоставленная иконка.

Как установить обновление:
1. На компьютере откройте папку D:\HanziPractice.
2. Распакуйте содержимое архива с заменой файлов, сохраняя структуру папок.
3. Запустите PowerShell в D:\HanziPractice и выполните: npx.cmd expo start -c
4. Проверьте изменения в Expo Go. APK пока не собирайте — сначала проверьте маркировку черт и переходы из экрана прогресса.

Важно:
- Идентификатор Android-пакета оставлен прежним, чтобы обновление могло устанавливаться поверх существующего приложения.
- Текстовые правки из feature.zip намеренно не переносились; их можно добавить отдельно позже.
- TypeScript-проверка (`tsc --noEmit`) завершилась без ошибок в рабочей копии. Полная проверка на реальном Android-устройстве ещё требуется.
